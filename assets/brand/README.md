# All You Need — 아이콘 시리즈

## 공통 특징

- 형태: 짙은 남색의 둥근 사각 타일, 부드러운 모서리와 얕은 입체감.
- 주 심볼: 따뜻한 아이보리색 도자기 질감. 작은 크기에서도 읽히는 굵은 형태.
- 시리즈 표식: 우측 상단의 라임색 네 갈래 별 하나. 중앙 심볼과 분리한다.
- 색상 기준: Midnight navy `#151D32`, warm ivory `#F5F1E8`, acid lime `#D5F86A`. 생성 이미지의 픽셀 색상을 보장하는 값이 아닌 제작 기준이다.
- 조명: 좌측 상단의 부드러운 빛과 절제된 그림자.
- 글자, 약자, 작은 장식은 사용하지 않는다.

## Quick Look

겹친 문서 두 장과 눈 모양의 미리보기 렌즈로 파일을 빠르게 들여다보는 기능을 표현한다.

`all-you-need-quicklook-v1.png`는 이미지 생성 도구로 제작한 아이콘 원본이다. 앱의 Asset Catalog 적용과 Dock/Finder에서의 검증은 별도다.

## 다음 프로젝트에 재사용

1. 이 아이콘을 이미지 참조로 첨부한다.
2. 타일 형태, 색상 계열, 질감, 조명, 우측 상단 별의 위치와 비율을 유지한다.
3. 중앙의 문서와 눈만 새 프로젝트의 기능을 나타내는 심볼로 교체한다.
4. 32px와 64px에서 중앙 심볼과 별이 구분되는지 확인한다.

생성만으로 프로젝트 간 형태가 완전히 일치하지는 않으므로, 새 아이콘은 이 원본과 나란히 비교한다. 재생성 시 `prompt.txt`와 참조 이미지를 함께 사용한다.
