## 변경된 동작과 한계

- `allowExternalImages` 기본값은 false. 기존 JSON에 키가 없어도 false이며, data 이미지에는 영향 없음. 선택 질문에 답변이 없어 보수적인 기본값을 작업 가정으로 명시한 뒤 적용했으며 사용자의 명시적 정책 선택으로 기록하지 않음.
- opt-in은 인터넷·내부망 이미지 요청 모두 허용한다. Settings에 그 범위와 preview 시점 노출을 설명한다. DNS/IP 필터를 구현했다거나 opt-in 상태에서 내부망 요청까지 차단한다고 주장하지 않음.
- 평문은 최대 262,144 UTF-16 단위 또는 10,000줄까지 표시하고 나머지는 잘림 안내. Unicode scalar 중간을 자르지 않음. 파일 읽기 자체는 기존의 전체 읽기 경로이며, 임의 크기 파일의 디스크 읽기/메모리 사용까지 제한한 변경은 아님.
- 로그 패턴은 기존 제한 문법과 compiler/matcher 예산 사용. lookaround·일부 ICU 문법 등 지원 밖 패턴은 건너뛰고 안내. 공유 matcher 예산은 패턴별 scan에 text를 차감하므로 기본 4개 패턴의 실효 강조 범위가 262,144자 전체와 같지 않다. 한 줄 16,384 UTF-16 초과는 강조를 건너뛰고 원문 표시. 실패한 run의 부분 결과는 적용하지 않음.
- 이 작업은 plain-text source line 통합이다. Markdown/notebook의 미래 DOM 패턴 강조, gutter·메타데이터 신기능, Settings pattern validation을 구현 완료로 간주하지 않음.
- 수식 pass는 텍스트 노드 단위다. 여러 HTML 요소를 가로지르는 수식 표현의 새로운 지원을 추가하지 않았으며 discovery/text/expression 한도에 걸리면 원문과 안내 유지.
