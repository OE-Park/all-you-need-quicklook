## 대상과 판정

기준 main `99c185015331881fb2230153b817f14c8a968fe4`, 수정 브랜치
`fix/host-preview-webkit`, 워크트리 `.worktrees/pr-merge`.
macOS 26.6.2 / Xcode 26.6. 최초 다크 검증에서 발견한 호스트 Preview 빈 화면을
호스트의 network.client entitlement 추가로 해결했다. 수정 후 라이트와 다크에서
샘플 4종(md/txt/log/ipynb)의 실제 렌더링을 확인했다.

## 원인과 변경

기준 빌드에서 호스트 Preview 샘플 4종이 비었고 WebKit 자식 프로세스의
`processDidTerminateOrFailedToLaunch: reason=Crash`와 sandbox extension 생성 실패가
반복되었다. 같은 빌드의 XCTest WKWebView와 Finder 확장은 성공했다.
호스트에만 `com.apple.security.network.client`가 없었다.

`project.yml`의 호스트에 해당 권한을 추가하고 XcodeGen으로 entitlements를 재생성했다.
서명된 앱에도 app-sandbox, application-groups, network.client가 적용됨을 codesign으로
확인했다. 이 한 가지 런타임 설정 변경 후 실제 호스트 미리보기가 복구되었다.
샌드박스의 로컬 HTML WebKit 실행에도 필요한 권한이라는
[동일 증상 보고](https://developer.apple.com/forums/thread/116359)와 부합한다.
이는 외부 연결 권한을 호스트에 추가하는 변경이다. CSP, nonce, 탐색 제한,
렌더러 소스 및 확장 권한은 변경하지 않았다.

## 재현 명령과 증거

```sh
xcodegen generate
xcodebuild test -project AllYouNeedQuickLook.xcodeproj -scheme Tests -destination 'platform=macOS' -derivedDataPath /private/tmp/quicklook-pr-validation
xcodebuild -project AllYouNeedQuickLook.xcodeproj -scheme AllYouNeedQuickLook -destination 'platform=macOS' -derivedDataPath /private/tmp/quicklook-pr-validation build
codesign -d --entitlements - /private/tmp/quicklook-pr-validation/Build/Products/Debug/AllYouNeedQuickLook.app
```

다크 probe 재실행: 시스템 다크 전환 → 아래 Swift 파일을 `Tests/`에 임시 복사 →
xcodegen generate → test → 임시 Tests 파일 제거 → xcodegen generate.
호스트 실제 회귀 검증: 빌드한 앱 실행 → Preview → 4개 샘플 선택 → 본문 시각 확인 →
라이트/다크 전환 → 본문 재확인. XCTest만으로 이 회귀를 통과 처리하지 않는다.

## 정리와 범위

검증 앱 종료 및 임시 등록 제거. PlugInKit에서 기존 5개 등록 유지 확인.
사용자가 전환한 시스템 다크 모드는 유지했다. 설치된 `/Applications` 앱을 교체하지 않았다.
이번 결과는 보고서의 빈 화면과 샘플 테마 검증에 한정한다. 아직 구현하지 않은
render-time 기능이나 외부 이미지 네트워크 동작의 신규 검증을 뜻하지 않는다.
